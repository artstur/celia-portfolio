Problem Space

A friend taps a photo in our chat, expects it to open, and tells me when it doesn’t. That message already describes the interaction, the expectation and the gap. What would it take for the workbench to use that feedback?

I built twelve plugins for DeepSeek Harness around a broader design question. If people can change a tool by describing what they need, which parts should the designer define up front, and which can take shape through use?

02. A Message Becomes a Product Change

A contact mentioned that tapping a picture in Messages did nothing. With automatic iteration enabled, the plugin picked up the feedback and opened a DeepSeek Harness session. The agent added a full-size image preview and recorded the change in Notes. The next time someone opened a picture in that workbench, a tap was all it took. They could use the feature without ever seeing the conversation that produced it.

The recording follows another small change, this time from my chat with myself. I wanted to edit my avatar in the same place as my name. You can follow the request from Messages to the agent’s work and the resulting version entry.
