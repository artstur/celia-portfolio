Problem Space

“I want to move more and sleep better” sounds simple. Keeping it going means noticing what changed: a tiring day, a workout already done, or a reminder that no longer fits.

I designed Along around that continuing conversation. The goal keeps its context, the next action can change, and the person can correct the plan in their own words.

01. Keep the Goal, Change the Next Step

“I’m tired today. Make it a twenty-minute walk, but keep the bedtime reminder.” A change like this belongs in the conversation where the goal began.

The current app turns an explicit request into a goal and tasks. Changes take effect after programmatic checks, and the person uses chat to correct them. Saying “I haven’t been sleeping well” starts a conversation; it does not automatically create a goal.

02. A Reminder That Remembers the Request

The bedtime reminder says to dim the lights, put down the screen and wind down at your own pace. It also preserves a preference: no fixed lights-out or wake-up time. The exercise reminder keeps the next step small: twenty minutes, at your own pace.

03. Follow Progress Without Another Prompt

Completing a workout should not require a second conversation just to update the plan. On iPhone, the person chooses which Apple Health summaries Along can use. Relevant changes can then trigger a review of an existing goal.

In an isolated test with a real model and synthetic health summaries, the agent removed an outdated “45 minutes still to do” task after reading the new exercise total. The goal stayed in place, and the validated task change took effect automatically.

04. Give the Agent Context and Boundaries

The phone handles conversation, health permissions and reminders. A paired Mac stores the goal and runs Along Agent on DeepSeek Harness. A Router connects new input to the right work; a Worker reads the relevant context and proposes structured changes. Code checks ownership, scope and versions before anything becomes part of the plan.

Local storage does not mean local inference: the configured model and memory services process the context sent to them. Memory extraction and recall have passed isolated checks; long-term usefulness in daily life is still being evaluated.

05. Evaluate the Decision and the Return Journey

My role spans the product behavior, prompts and context, evaluation scenarios, and acceptance of the resulting experience. An earlier evaluation set covered 54 synthetic decisions across exercise, savings and Cantonese practice. Each replay gave the agent only what was known at the decision point.

For Cantonese practice, understanding a phrase with subtitles and understanding it without them should lead to different next steps. For a reminder, a successful run is only part of the evidence: did it arrive, and did tapping it return to the intended task?

Current stage

Along is a personal prototype in use on a paired iPhone and Mac. Chat, task updates, scheduled reviews and memory have working implementations, with different levels of device validation. The public web demo can be explored with sample data; the paired agent flow requires the Mac service. Full retrospectives and automatic skill publishing remain future work.
