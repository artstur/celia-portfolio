Problem Space

Reviewing trading activity needs different evidence from planning a weekend hike. Both can change halfway through a conversation: a missing record, a new preference, or a route that feels too demanding.

I designed Along around the continuing goal. The agent breaks it into relevant tasks, recommends the sources it needs, and carries new instructions into the next step.

01. New Goals, Relevant Data Sources

Along can use the same workspace for a health routine, hiking research or a review of trading activity. A reminder, a research brief and a record-gathering step each serve a different kind of work. The tasks and suggested sources follow the goal.

02. A New Constraint Changes the Next Task

The original brief combined sleep, yoga bookings and a weekend hike. Along had included Wutong Mountain as a possible day trip. The person adds a constraint inside the existing goal: prioritise an easier walk.

Along revises the hiking task’s research criteria, removes Wutong Mountain from the shortlist, and returns three conditional route candidates. The broader routine stays in place.

03. A Reminder That Remembers the Request

The bedtime reminder says to dim the lights, put down the screen and wind down at your own pace. It also preserves a preference: no fixed lights-out or wake-up time. The exercise reminder keeps the next step small: twenty minutes, at your own pace.

04. Follow Progress Without Another Prompt

Completing a workout should not require a second conversation just to update the plan. On iPhone, the person chooses which Apple Health summaries Along can use. Relevant changes can then trigger a review of an existing goal.

In an isolated test with a real model and synthetic health summaries, the agent removed an outdated “45 minutes still to do” task after reading the new exercise total. The goal stayed in place, and the validated task change took effect automatically.

05. Give the Agent Context and Boundaries

On iPhone, Along handles chat, health permissions and reminders. A paired Mac routes work, checks task changes and stores context. Configured remote services provide model inference and memory retrieval.

Local storage does not mean local inference: the configured model and memory services process the context sent to them. Memory extraction and recall have passed isolated checks; long-term usefulness in daily life is still being evaluated.

06. Evaluate the Decision and the Return Journey

My role spans the product behavior, prompts and context, evaluation scenarios, and acceptance of the resulting experience. An earlier evaluation set covered 54 synthetic decisions across exercise, savings and Cantonese practice. Each replay gave the agent only what was known at the decision point.

For Cantonese practice, understanding a phrase with subtitles and understanding it without them should lead to different next steps. For a reminder, a successful run is only part of the evidence: did it arrive, and did tapping it return to the intended task?

Current stage

Along is a personal prototype in use on a paired iPhone and Mac. The November 17 captures add evidence for goal-specific source recommendations and research that responds to a new instruction. Chat, task updates, scheduled reviews and memory have working implementations, with different levels of device validation. The public web demo can be explored with sample data; the paired agent flow requires the Mac service. Full retrospectives and automatic skill publishing remain future work.
